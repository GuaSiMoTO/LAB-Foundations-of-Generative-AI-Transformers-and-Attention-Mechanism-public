# LAB-Foundations-of-Generative-AI-Transormers-and-Attention-Mechanism

## Comparing Attention Mechanisms: GPT-2 vs. DistilGPT2

### Introduction
In this lab, students will explore the differences between two Transformer models: **GPT-2** and its lighter variant, **DistilGPT2**. The goal is to compare the attention mechanisms of both models and visualize their attention matrices to understand how they process the same input differently. We will also compare the text generated by each model to see how the differences in attention affect the output.

Students will:
1. Generate text using GPT-2 and DistilGPT2.
2. Visualize the attention matrices for both models.
3. Compare the attention patterns and the resulting text.
